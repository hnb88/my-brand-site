date: "2026-09-28"
summary: "MDX 是 Markdown 的超集，能在文章里嵌入 React 组件，让内容活起来。"
---

这个网站的博客全部用 MDX 编写，说说我的理由。MDX 是 Markdown 的超集，除了普通排版，还能嵌入 React 组件，让内容活起来。

<Accordion title="MDX 上手难吗？">
会 Markdown 就能写，组件用法照葫芦画瓢就行。
</Accordion>

<Accordion title="写文章需要会写代码吗？">
普通文章不需要，用到互动组件时复制示例改一改即可。
</Accordion>

<Callout type="success" title="体验">
本站已内置提示框、标签页、步骤卡片等十多种组件，写文章时直接使用，效果生动得多。
</Callout>

如果你也在做个人站点，强烈建议试试 MDX。
