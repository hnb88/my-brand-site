## 网站技术栈

本网站使用以下技术构建：

- **Next.js 14** — React 全栈框架，前后端一体
- **TypeScript** — 类型安全的 JavaScript
- **Tailwind CSS v3** — 原子化 CSS 样式工具
- **shadcn/ui** — 基于 Radix 的 UI 组件库
- **Supabase** — 云数据库，存储客户评价数据
- **Vercel AI SDK + DeepSeek** — AI 客服对话能力
- **MDX** — 博客文章编写（Markdown + React 组件）
- **next-themes** — 深色/浅色模式切换
- **Umami** — 隐私友好的访问统计
- **Vercel** — 自动部署平台，连接 GitHub 推送即上线
- **GitHub** — 代码托管和版本管理
