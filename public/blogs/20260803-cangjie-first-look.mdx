上个月抽空把《图解仓颉编程》里的例子跑了一遍，说说感受。

语法上吸收了不少现代语言的设计：变量声明简洁，自带空安全，写起来很顺手。简单程序长这样：

```cangjie
func main() {
    let message = "你好，仓颉"
    println(message)
}
```

<Callout type="info" title="说明">
仓颉目前主要用于鸿蒙生态开发，建议先把官方文档快速入门过一遍。
</Callout>

整体感觉：适合有 C 系语言基础的人，值得投入时间。
